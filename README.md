# Лабораторная работа №6. Введение в Node.js и базовый сервер на Express

**Выполнил:** Лесников Лев, группа 932402  
**Вариант:** 20, тема «API статуса сервера» (расширенный)

## Цель работы
Освоить запуск Node.js-приложений, работу с модулями, создание простого HTTP-сервера, а также превращение статического сайта в PWA (устанавливаемое приложение с офлайн-режимом).

## Задание
- Инициализировать проект (`npm init`), установить Express.
- Создать сервер, который отдаёт статические файлы (HTML, CSS, JS).
- Реализовать несколько маршрутов: `/` (главная), `/about` (о себе), `/api/status` (JSON-ответ).
- Научиться работать с параметрами запроса и query-параметрами.
- Добавить манифест (`manifest.json`) с иконками и подключить его в HTML.
- Реализовать service worker: кешировать статику и обеспечить работу приложения офлайн, зарегистрировать его на странице.

### Требования варианта 20
- **Маршруты:** `GET /`, `GET /about`, `GET /api/status`.
- **Логика:** возвращает объект `{ uptimeSeconds, memoryUsageMB, cpuCount, timestamp }`, где `timestamp` в формате ISO.
- **Источники данных:** `process.uptime()`, `process.memoryUsage()`, `os.cpus()`.
- **Ответ:** объект с метриками.
- **Ошибки:** отсутствуют.

## Структура репозитория
- `server.js`: сервер на Express с маршрутами `/`, `/about`, `/api/status` и раздачей статики из папки `public`;
- `package.json`: конфигурация проекта и зависимость `express`;
- `public/index.html`: главная страница с отображением метрик сервера;
- `public/about.html`: страница «О себе»;
- `public/style.css`: стили оформления страниц;
- `public/app.js`: клиентский скрипт для запроса `/api/status`, регистрации Service Worker и установки PWA;
- `public/sw.js`: Service Worker для кеширования статики и работы в офлайн-режиме;
- `public/manifest.json`: манифест PWA;
- `public/icons/icon-192.png`, `public/icons/icon-512.png`: иконки приложения;
- `README.md`: описание лабораторной работы.

## Инструкция по запуску и проверке
1. Установить зависимости командой `npm install`.
2. Запустить сервер командой `npm start` (или `node server.js`).
3. Открыть `http://localhost:3000/` в браузере и проверить загрузку главной страницы и метрик сервера.
4. Перейти на `/about` и проверить отображение страницы «О себе».
5. Открыть `/api/status` (можно также проверить query-параметры `?type=rss` и `?raw=true`) и убедиться, что возвращается JSON с полями `uptimeSeconds`, `memoryUsageMB`, `cpuCount`, `timestamp`.
6. Открыть DevTools (`F12`), перейти во вкладку Application, проверить подключение `manifest.json` и регистрацию Service Worker (`sw.js`).
7. Включить режим Offline в DevTools и перезагрузить страницу, чтобы убедиться, что статические страницы открываются в офлайн-режиме.
